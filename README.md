# Part 107 Prep

Mobile-friendly practice quiz for the FAA Part 107 Remote Pilot (UAG) knowledge test.

- Practice by topic, with an explanation after every question
- 60-question, 2-hour mock exam with a pass/fail score and a breakdown by topic
- Review of missed questions, plus progress saved in your browser

Static site with no build step: deploy on Vercel as-is.
Add questions in `questions.js`. Change the exam date at the top of the script in `index.html`.
